# This Mac (agents read this first)

A family member's own Mac (`ssh colin-mac`, `ssh colton-mac`, ...), reached through Cloudflare Access from that
person's nextjs container, the owner's container and fcvm-metal-arm. It is their computer: they may be sitting at it.
Installed and kept current by ejc3/aws `scripts/mac-setup.sh <alias>`; the section marked "found" below is written by
`mac-agents-md` (hourly, and at every setup). Do not edit this file by hand: change `scripts/mac/member-mac-AGENTS.md`
in ejc3/aws.

## Rules

- **Their account, their things.** Work in your own folder; change no account, password, payment, purchase, system
  setting or app setting the person did not ask for, and act only in windows you opened. Never delete their files or
  their Claude conversations.
- **Never leave the only copy of work here**: commit and push from the dev box. The Mac sleeps, travels and goes offline.
- **Check it is up first**: `timeout 15 ssh <alias> true`. It answers only while the Mac is awake, logged in and online.
- **The screen is theirs.** Drive it (Peekaboo, `--foreground`) only when the person or the owner asked for that task;
  `--foreground` is Peekaboo's guard, not a permission you give yourself. Take the desktop lease first
  (`mac-lease run NAME -- CMD`); `peekaboo` waits while another session holds it.
- **No Homebrew** unless the person installed it. `~/.local/bin` is first on PATH in every SSH session.
- **Keychain:** plain SSH cannot reach the login keychain (GitHub logins, signing); run such a step through
  `mac-gui [--timeout S] -- CMD`.

## Claude on this Mac and the shared pool

"Found: Claude and the shared pool" below says whether this Mac is on the pool. When it is, every Claude Code here (the
`claude` CLI, IDE extensions, and the Claude desktop app's **local** Code sessions) goes through `claw-master agent`
(`~/.claude/settings.json` env; ejc3/aws `scripts/claw-master-mac-setup.sh <alias> --default`). Two things that look
like "the pool is broken" and are not:

- **The desktop app's Code tab defaults to a cloud environment** ("Default", a cloud icon). A cloud session runs on
  Anthropic's servers on the person's own account and its own weekly limit, never through the pool. Choose
  environment **Local** for a session that uses the pool. Ordinary chat in the app is always the person's own account.
- **Claude Code still needs the person's own login** (`claude`, then `/login`) before it sends anything; without one it
  stops at "Not logged in" and the pool never sees the request.

The agent's log (`~/Library/Logs/claw-master-agent.log`) records starts, not requests: `lsof -nP -iTCP:8445
-sTCP:ESTABLISHED` shows the sessions using it right now. `claw-master agent uninstall` undoes the switch.

## Driving the screen: Peekaboo 4

- Screenshot: `peekaboo see --no-elements --path /tmp/shot.png` (`peekaboo image` was removed in v4); add `--app NAME`
  for one app's window.
- Keys: `peekaboo press cmd+n --app NAME --foreground` (`hotkey` was removed). Switching apps and raw key presses are
  refused without `--foreground`, Peekaboo's consent that interrupting the person's foreground app is intended.
- Check the grants with `peekaboo permissions status`; they are given once at the Mac to the Peekaboo app (Screen
  Recording, Accessibility, Event Synthesizing), never to Terminal.
