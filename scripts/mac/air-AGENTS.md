# This Mac (agents read this first)

The owner's MacBook Air (M2, 8 cores), their second Mac, reached with `ssh air` from a dev box. Installed and kept
current by ejc3/aws `scripts/mac-setup.sh`; the section marked "found" below is written by `mac-agents-md` from what
is on the machine now (hourly, and at every setup). Do not edit this file by hand: change `scripts/mac/air-AGENTS.md`
in ejc3/aws.

## Rules

- **Builds go to the Mac mini** (`ssh mini`) unless the task needs this Mac: the owner's signed-in browser, its login
  keychain, or something attached to it. This is a laptop with a small disk and no scratch drive: keep build products
  out of the home directory and delete what you made when you are done.
- **The desktop lease:** take it (`mac-lease run NAME -- CMD`) before driving the screen or relaunching an app;
  `peekaboo` waits while another session holds it. The owner may be using this Mac: look before you take the screen.
- **Signing:** run the signing step through `mac-gui [--timeout S] -- CMD`, which reaches the login keychain; plain SSH
  gets `errSecInternalComponent`.
- Act only in windows you opened; change no account, payment or setting the owner did not ask for.
- **Peekaboo 4:** screenshot with `peekaboo see --no-elements --path FILE` (`image` was removed), keys with
  `peekaboo press cmd+n --app NAME --foreground` (`hotkey` was removed); app switches and raw key presses are refused
  without `--foreground`.
- **Claude here uses the shared pool** (the `claw-master` agent on `127.0.0.1:8445`, set in `~/.claude/settings.json`).
  The desktop app's Code tab uses it only in a **Local** environment; a cloud environment runs on Anthropic's servers on
  the owner's own limits.
