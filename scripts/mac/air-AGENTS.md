# This Mac (agents read this first)

A MacBook Air (M2, 8 cores, 24 GB), reached with `ssh air` from a dev box. It is CI and agent capacity, not
anyone's personal machine (owner, 2026-11-28). Installed and kept current by ejc3/aws `scripts/mac-setup.sh`; the
section marked "found" below is written by `mac-agents-md` from what is on the machine now (hourly, and at every
setup). Do not edit this file by hand: change `scripts/mac/air-AGENTS.md` in ejc3/aws.

## Rules

- **CI runs in the `air-ci` tart VM**, not on the host: dolphin-labs-hq's runner `air-ci-1` (`ios-pool`,
  `ios-simulator`) lives there, kept running by a LaunchAgent. Never stop, delete or reconfigure that VM while it holds a
  job; `tart list` shows it. Host Xcode's licence is not accepted, so host `xcodebuild` and host `python3` (the Xcode
  stub) do not work; build inside the VM or on the Mac mini (`ssh mini`).
- **The disk is small** (about 228 GB, no scratch drive): keep build products and DerivedData out of the home
  directory and delete what you made when you are done.
- **The desktop lease:** take it (`mac-lease run NAME -- CMD`) before driving the screen or relaunching an app;
  `peekaboo` waits while another session holds it. Other agents use this Mac too: look before you take the screen.
- **Signing:** run the signing step through `mac-gui [--timeout S] -- CMD`, which reaches the login keychain; plain SSH
  gets `errSecInternalComponent`.
- Act only in windows you opened; change no account, payment or setting nobody asked for.
- **Peekaboo 4:** screenshot with `peekaboo see --no-elements --path FILE` (`image` was removed), keys with
  `peekaboo press cmd+n --app NAME --foreground` (`hotkey` was removed); app switches and raw key presses are refused
  without `--foreground`.
- **Claude here uses the shared pool** (the `claw-master` agent on `127.0.0.1:8445`, set in `~/.claude/settings.json`).
  The desktop app's Code tab uses it only in a **Local** environment; a cloud environment runs on Anthropic's servers on
  its own limits.
